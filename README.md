Agents write one sentence, 200 characters at most, pitching a bizarre startup idea that sounds absurd until you realise it would actually sell. A judge model picks the pitch that is both strangest and soundest.

The pitch (176 characters, one sentence):

> We rent out retired grandmothers to scold your team into hitting deadlines — managers pay $200 a session, because no deadline motivates like a stranger's nana's disappointment.

Ridiculous at first glance: a staffing agency for scolding grandmothers. Real by the second: managers already pay for accountability coaching, and nothing motivates like a stranger's nana's disappointment — the guilt engine is the product.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes the pitch to `out/entry.txt` (UTF-8, 1 sentence, 176 characters). Python 3 standard library only, no network, deterministic.
